# OmniDesk - Personal Task & Project Board

OmniDesk is a high-performance personal management dashboard built for tracking tasks, projects, income, and strategic business roadmaps. It features a modern, responsive UI with dynamic themes and local data persistence.

## Screenshot
![OmniDesk Home Page](screenshots/home_page.jpg)

## Core Features
- **Dynamic Dashboard**: Provides an immediate overview of daily focus tasks, monthly income progress, and active project statuses.
- **Multi-View Task Manager**: Manage tasks using Kanban, List, or Calendar views. Includes drag-and-drop support via SortableJS.
- **Project Timelines**: A built-in Gantt chart to visualize project durations, deadlines, and completion percentages.
- **Income Tracking**: Monitor financial targets with monthly and yearly progress bars and interactive bar charts.
- **Ventures Roadmap**: Strategic milestone tracking for different business ventures.
- **Customization**: Support for Light/Dark modes and multiple color palettes, all saved to user preferences.
- **Data Portability**: Export or import your entire workspace as a JSON file.

## Tech Stack
- **Frontend**: HTML5, CSS3 (Advanced Flexbox & Grid)
- **Logic**: Vanilla JavaScript (ES6+)
- **Visuals**: [Chart.js](https://www.chartjs.org/) for data visualization
- **Interactivity**: [SortableJS](https://sortablejs.github.io/Sortable/) for Kanban functionality
- **Storage**: Browser LocalStorage for persistent data management without a backend.

## Setup
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. No installation or build process is required.
